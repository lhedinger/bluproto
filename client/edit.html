genome editor

A genome taken apart for a form: the body's genes within the bounds a birth would clamp them to, the clade, and the mind's program one instruction a row. Load one from a creature, a .genome file or a pasted line, change it, and save it or hand it to the world to place. The editor edits numbers, never text: the line it writes is the simulation's own encoding, and the disassembly beside the program is read back from it. Nothing here changes a living creature; what you place is a new founder of its own line.
